# Few-shot Helicopter Image Classification with DINOv3

Official implementation of the experiments in:

> **基于DINO视觉大模型的少样本直升机图像分类方法研究**
> (Few-shot helicopter image classification based on the DINOv3 self-supervised vision foundation model)

The pipeline: frozen DINOv3 ViT-L/16 backbone -> CLS feature -> MLP head with ArcFace loss
(frozen-backbone stage), followed by LoRA (r=16, alpha=32) joint fine-tuning with
class-balanced sampling, evaluated on a 9-class, 731-image, class-imbalanced (7.6:1)
helicopter dataset derived from the [Military Aircraft Detection Dataset](https://www.kaggle.com/datasets/a2015003713/militaryaircraftdetectiondataset).

## Repository layout

```
heli-fewshot-dinov3/
├── extract_features.py        # DINOv3 feature pre-extraction (CLS + Patch-Mean, raw + 5x augmented)
├── run_arcface.py             # Ours (frozen backbone): CLS + MLP + ArcFace, 5 ratios x 3 seeds   -> Tables 2-3
├── run_linear_aug5.py         # Baseline: frozen backbone + single linear head + CE, 3 seeds    -> Tables 2-3
├── run_resnet50.py            # Baseline: ImageNet ResNet-50 end-to-end fine-tuning (1 seed)    -> Tables 2-3
├── run_ablation.py            # Ablations: feature / head / loss / augmentation / hid / dropout -> Tables 4-6
├── run_vit_lora_arcface.py    # Ours + LoRA joint fine-tuning, 25% data, 1 seed                 -> Table 7
├── eval_confusion.py          # Test-set confusion matrix of the LoRA model                     -> Fig. 5
├── data/
│   ├── splits/split_311.json  # fixed stratified 3:1:1 split (train 435 / val 142 / test 154)
│   ├── crop/{AH64,CH47,...}/  # cropped helicopter images (NOT included, see Data preparation)
│   └── features/              # generated by extract_features.py (not included)
├── results/                   # generated metric JSON files
├── models/                    # saved LoRA checkpoints
└── ckpts/                     # resumable training checkpoints
```

## Environment

- Python 3.10+
- PyTorch 2.10.0 + CUDA (tested on a single NVIDIA GeForce GTX 1660, 6 GB)
- `pip install -r requirements.txt`
- DINOv3 weights: `facebook/dinov3-vitl16-pretrain-lvd1689m` (Hugging Face; gated — accept the
  license on the model page and `huggingface-cli login` first. `HF_ENDPOINT=https://hf-mirror.com`
  is set as a fallback mirror inside the scripts.)

## Data preparation

The image data are **not** redistributed in this repository. To reproduce:

1. Download the [Military Aircraft Detection Dataset](https://www.kaggle.com/datasets/a2015003713/militaryaircraftdetectiondataset)
   (military aircraft images with aircraft type and bounding-box annotations).
2. Keep the 9 helicopter classes: `AH64, CH47, CH53, Ka27, Ka52, Mi24, Mi26, Mi28, NH90`.
3. Crop every image to the helicopter body using the provided bounding boxes (remove large
   sky/ground background), and remove broken / heavily overlapping / mislabelled samples.
   This yields **731 images** with the class distribution reported in Table 1 of the paper
   (largest class AH64: 206, smallest NH90: 27).
4. Organize as class folders:

```
data/crop/
├── AH64/  *.jpg
├── CH47/  *.jpg
...
└── NH90/  *.jpg
```

The fixed 3:1:1 stratified split is in `data/splits/split_311.json` and must be used as-is
so that all numbers are directly comparable.

## Reproducing the paper

```bash
# 1. Pre-extract DINOv3 features (required by the three frozen-backbone scripts)
python extract_features.py

# 2. Main comparison (Tables 2-3): frozen-backbone methods, 5 ratios x 3 seeds
python run_arcface.py            # Ours: CLS + MLP + ArcFace      e.g. 25%: Bal Acc 0.823+-0.032
python run_linear_aug5.py        # Baseline: linear head           e.g. 25%: Bal Acc 0.615+-0.020

# 3. ResNet-50 baseline (Tables 2-3, single run)
python run_resnet50.py

# 4. Ablation study at 25% data (Tables 4-6), 6 groups x 3 seeds
python run_ablation.py

# 5. LoRA joint fine-tuning at 25% data (Table 7); ~hours on a GTX 1660
python run_vit_lora_arcface.py 42        # e.g. Test Acc 0.929 / Bal Acc 0.900

# 6. Confusion matrix of the LoRA model (Fig. 5b)
python eval_confusion.py 42
```

Key reported results (25% training data, balanced accuracy, mean +- std over seeds 42/123/2024):

| Method | Bal Acc |
|---|---|
| ResNet-50 fine-tuning (single run, 100%/25%) | 0.779 / 0.494 (Test Acc) |
| Linear head | 0.615 ± 0.020 |
| **Ours (CLS + MLP + ArcFace, frozen)** | **0.823 ± 0.032** |
| **Ours + LoRA joint fine-tuning (single run)** | **0.900** (Test Acc 0.929) |

## Notes

- DINOv3 features are extracted in **fp32**; fp16 autocast is only used inside LoRA training.
- `run_arcface.py` / `run_linear_aug5.py` / `run_ablation.py` consume the pre-extracted
  `.npz` feature files, so they run in minutes even without a GPU.
- Training-data sub-sampling (6.25%/12.5%/25%/50%/100%) is performed on the fly with the
  per-seed stratified sampler inside each script (deterministic given the seed).
- The LoRA script supports resuming from `ckpts/` automatically.
